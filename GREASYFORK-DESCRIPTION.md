Import your entire Fortnite locker to fortnite.gg with **one click**. Free, open source (MIT), no downloads, no .exe, no password sharing.

> **Project status:** This project is no longer actively developed. Epic Games removed my Support-A-Creator code, which was the only income this project had. The script keeps working as it is and stays free, and I'll still try to fix it if something breaks completely. No new features are planned.

## What it does

Imports all your cosmetics (skins, pickaxes, emotes, wraps, banners, instruments, cars, LEGO kits and more) to your fortnite.gg locker, sorted by type and rarity. Shows you how many items are new since your last import. Works with lockers of 8000+ items.

Also includes:

- Account stats panel (V-Bucks, wins, season history and more)
- Collection breakdown by rarity and type
- Selective import filter
- Saveable filter presets
- Clickable chapter filter
- Background check for new items
- Wishlist tools: how many you own, clear owned in one click, highlights on your wishlist page, and a shop alert when a wishlisted item is in the shop

## Is this safe?

Yes. You login on Epic's **official** website (Device Code flow), the script never sees your password.

- On your Epic account the script only reads data, there are no write actions. It cannot buy anything.
- The token expires after about 2 hours and is cleared automatically after the import (default, can be turned off in settings).
- No data collection.
- Every line of code is readable. Don't take my word for it: paste the script into any AI and ask it to audit the code.

## How to use

1. Install this script
2. Open fortnite.gg and follow the panel on the right
3. Connect your Epic account, login, click **Import Locker**. Done!

A guided tour walks you through your first import. Available in 13 languages, auto-detected from the page.

## Note

Desktop browsers only (Chrome, Firefox, Edge), on Windows, Mac or Linux. Mobile browsers do not support userscripts.
